# Personal To-Do List

A simple beginner-friendly To-Do List built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser localStorage
- Restore tasks after refreshing the page

## Technologies Used

- HTML
- CSS
- JavaScript
- localStorage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add, complete, or delete tasks.

## What I Learned

- HTML page structure
- CSS styling and layout
- JavaScript DOM manipulation
- Event listeners
- Arrays and objects
- Saving data with localStorage
